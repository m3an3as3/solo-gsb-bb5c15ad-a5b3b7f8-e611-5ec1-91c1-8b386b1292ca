# SRT 字幕时间校准工具

在浏览器中校准 SRT 字幕的时间轴：设置若干个 **“原字幕时刻 → 视频实际时刻”锚点**，
工具会按原时刻对锚点排序，在相邻锚点之间做**线性插值**，首尾两端按最近一段的
斜率**外推**，统一换算每一条字幕的开始与结束时间。

## 功能

- 粘贴文本或上传 `.srt` 文件（原生浏览器页面，无需任何前端构建）
- 至少 2 个锚点，支持 `HH:MM:SS,mmm`（也可简写 `MM:SS,mmm`）
- 校验锚点：
  - **原时刻重复** → 拒绝
  - **映射时刻不随原时刻严格递增** → 拒绝
- 表格预览每条字幕的原起止、校准后起止与正文（保留原序号）
- 自动标出问题字幕（整行标红 + 标签）：
  - **负时间**：校准后开始或结束时间小于 0
  - **起止倒置**：校准后开始时间晚于结束时间
  - **与下一条重叠**：校准后结束时间晚于下一条的开始时间
- 存在任何问题字幕时**禁止导出**；全部正常时一键下载 `calibrated.srt`，
  保留原序号与正文，仅重写时间轴

## 启动（一条命令）

```bash
docker compose up --build -d
```

启动后在浏览器打开：

**http://localhost:8000**

停止服务：

```bash
docker compose down
```

## 本地（不使用容器）开发

依赖随容器自动安装；本地运行需 Python 3.10+：

```bash
pip install -r requirements.txt
uvicorn app.main:app --host 0.0.0.0 --port 8000
```

同样访问 http://localhost:8000 。

## HTTP 接口

| 方法 | 路径 | 说明 |
| --- | --- | --- |
| `POST` | `/api/preview` | 入参 `{content, anchors:[{original,mapped}]}`，返回每条字幕校准结果与问题标记 |
| `POST` | `/api/export` | 入参相同；无问题时返回 `calibrated.srt` 文件，有问题返回 422 错误 |
| `GET` | `/api/health` | 健康检查 |

## 校准算法

设有序锚点为 `(tᵢ, Tᵢ)`（原时刻 → 实际时刻）：

- `tᵢ ≤ t ≤ tᵢ₊₁`：`T(t) = Tᵢ + (Tᵢ₊₁ − Tᵢ) · (t − tᵢ) / (tᵢ₊₁ − tᵢ)`
- `t < t₀`：沿用第一段斜率外推
- `t > tₙ`：沿用最后一段斜率外推

每条字幕的开始、结束时间分别按上式独立换算，结果四舍五入到毫秒。
